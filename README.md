# ระบบนำทางอพยพ / Building Evacuation Guide

Web app ที่ช่วยคนอพยพออกจากอาคาร: เมื่อเกิดเหตุ ระบบจะ **ถามว่าคุณอยู่ตรงไหน**
จากนั้นคำนวณเส้นทางที่สั้นที่สุด/ปลอดภัยที่สุดไปยัง **จุดรวมพล (safe zone)** นอกอาคาร
พร้อมแสดงแผนผังชั้น บันไดหนีไฟ และขั้นตอนเดินทีละชั้น

> อาคารตัวอย่าง 5 ชั้น (Demo Building) — ไม่ผูกกับอาคารจริง เปลี่ยนข้อมูลแผนผังได้
> โดยแก้ที่ส่วน `FLOORS` ใน `public/index.html`

## เริ่มใช้งาน (local)

```bash
cd evacuation-app
npm install
npm start          # http://localhost:3001
```

เปิดเบราว์เซอร์ → กด **🆘 เริ่มนำทางอพยพ** → พิมพ์ชื่อห้อง (เช่น `205`, `Office 401`,
`Library`, `Lobby`) หรือแตะห้องบนแผนผัง → ระบบวาดเส้นทางและแสดงวิธีเดิน

หรือเรียกใช้ผ่าน URL โดยไม่ต้องรัน server ก็ได้ (เปิด `public/index.html` ตรงๆ)

## วิธีใช้งาน

1. **ค้นหาห้อง** — พิมพ์ชื่อห้องภาษาไทย/อังกฤษในช่องค้นหา หรือกดปุ่มเริ่มแล้วเลือกจากรายการ
2. **แตะบนแผนผัง** — กดที่ห้องตัวเองบน SVG floor plan ได้เหมือนกัน
3. ระบบคำนวณเส้นทางด้วย Dijkstra เหนือกราฟตึก (โถงทางเดิน + บันได + ทางออก)
   → เลือกจุดรวมพลที่ใกล้สุดอัตโนมัติ (A หน้าอาคาร / B หลังอาคาร)
4. แผงด้านขวาแสดงขั้นตอน: ออกจากห้อง → เดินโถงทางเดิน (ซ้าย/ขวา + ระยะเมตร)
   → ลงบันไดทีละชั้น → ออกจากอาคาร → ถึงจุดปลอดภัย พร้อมระยะทางรวมและเวลาประมาณ
5. สลับดูชั้นอื่นด้วยแท็บเพื่อดูเส้นทางส่วนที่อยู่ชั้นนั้น

## โครงสร้าง

```
evacuation-app/
├─ public/index.html   ตัวแอปทั้งหมด (ไฟล์เดียว, ไม่ต้อง build)
├─ server.js           Express  serve static (dev/local)
└─ package.json
```

## การต่อยอด

- **เปลี่ยนอาคารจริง** — แก้ `FLOORS`, `STAIRS`, ขอบเขตห้อง และตำแหน่งทางออกใน
  `public/index.html` (ทุกอย่างเป็นข้อมูลในไฟล์เดียว)
- **ปลั๊กข้อมูลเหตุการณ์ (fire/smoke block)** — เพิ่ม edge ที่ "ตัด" บันไดที่ไม่ปลอดภัย
  ออกก่อนรัน Dijkstra ระบบก็จะอ้อมไปอีกบันไดให้อัตโนมัติ
- **API/backend** — ตอนนี้เป็น static ล้วน ถ้าต้องการผู้ดูแลอัปเดตแผนผังผ่านเว็บ
  ย้ายข้อมูลไป JSON + endpoint แล้วโหลดตอนเปิดหน้า (รูปแบบเดียวกับโปรเจกต์
  `huahin-cctv` ที่มีอยู่)
- **QR ต่อห้อง** — แปะ QR ที่หน้าห้องลิงก์ `?room=Lecture+202` เปิดแล้วเลือกห้องอัตโนมัติ

## หมายเหตุความปลอดภัย (ตั้งใจไว้ในการวัด)

- เส้นทางใช้บันไดหนีไฟเสมอ — **ไม่ใช้ลิฟต์** (วาดเตือนไว้ในแผนผัง)
- มีจุด "ที่หลบอัคคี (Refuge)" ข้างบันไดทุกชั้น ไม่นับเป็นทางออกสุดท้าย
- ระยะทางและเวลาเป็นการประมาณเพื่อการสื่อสาร ไม่ใช่ค่าทางวิศวกรรมหนีไฟ

## การทดสอบ

ไม่มี test suite; ทำการตรวจสอบง่ายๆ ได้ด้วย:

```bash
npm start
# เปิด http://localhost:3001 ตรวจ: ค้นหา → เลือกห้อง → เส้นทางขึ้นในทุกชั้น
# ตรวจจาก console: window._api.dijkstra / buildSteps คืนผลในแต่ละจุดเริ่ม
```
